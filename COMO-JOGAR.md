# Como jogar

Baixe index.html e abra no navegador. Use Espaço, seta para cima ou o botão PULAR. Dois toques dão pulo duplo. P pausa. Há três vidas e dois ritmos. Colete anéis e chegue à bandeira.

## Link para jogar no GitHub Pages

Em Settings → Pages → Build and deployment, escolha Deploy from a branch, branch main, pasta / (root), e salve. Aguarde o GitHub informar o endereço publicado. O envio do código não ativa o Pages automaticamente.
