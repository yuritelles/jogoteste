# Sonic • Corrida dos Anéis

Jogo de plataforma em HTML Canvas, sem dependências externas. Escolha Sonic ou Tails, colete anéis e alcance a esmeralda.

## Jogar

Abra `index.html` em um navegador. No celular, use os botões da tela, preferencialmente na horizontal.

- Setas ou A/D: mover.
- Espaço, seta para cima ou W: pular (Sonic: 2 saltos; Tails: 3).
- Shift ou botão Turbo: acelerar e derrotar robôs.
- P: pausar/continuar.
- Som opcional, ativado pelo botão no cabeçalho.

## Publicar no GitHub Pages

Em Settings → Pages, selecione Deploy from a branch, branch `main`, pasta `/ (root)` e Save. O código já está pronto para essa publicação.

## Verificação

Verificados: sintaxe JavaScript, saltos duplo/triplo, coleta de anéis, conclusão da fase e pausa/retomada. A tela inicial foi inspecionada no navegador; dispositivos físicos não foram testados.

Fan game experimental. Sonic e Tails pertencem à SEGA. Desenhos feitos em Canvas, sem assets externos.
